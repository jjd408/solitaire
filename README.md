# Solitaire handheld

A pocket solitaire game: a TI MSP430FR2355 microcontroller drives a Sharp LS013B7DH05 memory LCD, runs from
two AA cells through a TPS63900 buck-boost regulator, and is played with 16 push buttons. The memory LCD keeps its
image without refresh, so the board sleeps almost all the time and wakes when a button is pressed.

## What's here

| Folder | Contents |
| --- | --- |
| `hw/` | Hardware design notes: parts, design decisions, open items ([hw/README.md](hw/README.md)). |
| `hw/sol/` | The KiCad 9 project: schematic (passes ERC) and PCB (layout in progress). |
| `hw/lib/` | The project's KiCad library (symbols, footprints, 3D models), generated by the scripts beside it ([hw/lib/README.md](hw/lib/README.md)). |
| `docs/datasheets/` | Datasheets for the parts, with text extracts used while building the library. They belong to their vendors (TI, Sharp, Panasonic, Murata, ALPS). |

## Simulator

The firmware can run before the hardware exists, in a copy of PICSimLab with an MSP430FR2355 backend, the
LS013B7DH05 display and a "Solitaire" board wired like `hw/sol`:
[github.com/jjd408/picsimlab-msp430](https://github.com/jjd408/picsimlab-msp430). Clone it into `sim/` to keep
the layout these notes assume:

```sh
git clone https://github.com/jjd408/picsimlab-msp430 sim/picsimlab-msp430
```

## Tools

- KiCad 9 for `hw/sol`; open `hw/sol/sol.kicad_pro`. The library tables use paths relative to the project.
- Python 3 to regenerate the library (`hw/lib/make_symbols.py`, `make_footprints.py`), FreeCAD 1.0 for the 3D
  models (`freecadcmd hw/lib/make_lcd_model.py`, `make_switch_model.py`).
- TI MSP430-GCC (`msp430-elf-gcc -mmcu=msp430fr2355`) for firmware.
