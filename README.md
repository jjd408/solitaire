# Solitaire handheld

A pocket solitaire game: a TI MSP430FR2355 microcontroller drives a Sharp LS013B7DH05 memory LCD, runs from
two AA cells through a TPS63900 buck-boost regulator, and is played with 16 push buttons. The memory LCD keeps its
image without refresh, so the board sleeps almost all the time and wakes when a button is pressed.

## What's here

| Folder | Contents |
| --- | --- |
| `hw/` | Hardware design notes: parts, design decisions, open items ([hw/README.md](hw/README.md)). |
| `hw/sol/` | The KiCad 9 project: schematic (passes ERC) and routed PCB (passes DRC). |
| `hw/lib/` | The project's KiCad library (symbols, footprints, 3D models), generated by the scripts beside it ([hw/lib/README.md](hw/lib/README.md)). |
| `hw/case/` | A 3D-printed case generated from the board: front and back shells and button caps, as STL files ([hw/case/README.md](hw/case/README.md)). |
| `hw/ORDERING.md` | How to order the boards (JLCPCB, assembled), the displays and the battery holders. |
| `sw/` | Firmware, in assembly: the plan ([sw/PLAN.md](sw/PLAN.md)), a document per step (`sw/STEP1-skeleton.md` ... `STEP11-bringup.md`) and the NetBeans MSP430 project `sw/sol`, with its tests in `sw/sol/tests`. |
| `docs/datasheets/` | Datasheets for the parts, with text extracts used while building the library. They belong to their vendors (TI, Sharp, Panasonic, Murata, ALPS). |

## Status

- **Firmware: finished in the simulator** (steps 1-10 of the plan). The whole game plays: moves, undo, scoring,
  options and statistics, the game kept through power loss. `sw/sol/tests/run.sh` checks it on the simulator: 39
  tests, including a whole winning game and screen pictures, with what's kept in FRAM compared byte for byte
  against a Python model of the firmware.
- **Board: ready to order.** Schematic and layout pass ERC and DRC; `hw/sol/make_fab.sh` writes the order files.
- **Case: designed**, not yet printed.
- **Next: building it.** Order the boards and displays (`hw/ORDERING.md`), then bring them up
  (`sw/STEP11-bringup.md`).

## Simulator

The firmware can run before the hardware exists, in a copy of PICSimLab with an MSP430FR2355 backend, the
LS013B7DH05 display and a "Solitaire" board wired like `hw/sol`:
[github.com/jjd408/picsimlab-msp430](https://github.com/jjd408/picsimlab-msp430). Clone it into `sim/` to keep
the layout these notes assume:

```sh
git clone https://github.com/jjd408/picsimlab-msp430 sim/picsimlab-msp430
```

## Tools

- KiCad 9 for `hw/sol`; open `hw/sol/sol.kicad_pro`. The library tables use paths relative to the project.
- Python 3 to regenerate the library (`hw/lib/make_symbols.py`, `make_footprints.py`), FreeCAD 1.0 for the 3D
  models (`freecadcmd hw/lib/make_lcd_model.py`, `make_switch_model.py`).
- TI MSP430-GCC (`msp430-elf-gcc -mmcu=msp430fr2355`) for firmware; Apache NetBeans with the MSP430 Assembly
  plugin ([github.com/jjd408/msp430-asm](https://github.com/jjd408/msp430-asm)) to edit, build, run and debug it.
- FreeCAD 1.0 for the case (`hw/case/make_case.sh`).
