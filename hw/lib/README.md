## Files

- `solitaire.kicad_sym`: the symbol library. Generated by `make_symbols.py`; edit the pin tables there and rerun
  it rather than editing the library by hand.
- `3d/LS013B7DH05.step`, `3d/LS013B7DH03.step` and their `.FCStd` files: the displays, for KiCad's 3D view and
  for modeling the case in FreeCAD. Generated by `freecadcmd make_lcd_model.py`; each display's dimensions are a
  table at the top of that script.
- `solitaire.pretty/`: the footprint library. Generated by `make_footprints.py`.
- `3d/SW_Alps_SKRPACE010.step` and `.FCStd`: the button. Generated by `freecadcmd make_switch_model.py`. The footprint
  finds it at `${KIPRJMOD}/../lib/3d/`, so it shows in KiCad's 3D view when this folder sits beside the project's
  folder, as `hw/lib` sits beside `hw/sol`.
- Datasheets the parts were built from are in `../../docs/datasheets/`.

## Adding the library to a KiCad project

Preferences > Manage Symbol Libraries > Project Specific Libraries > add `${KIPRJMOD}/../lib/solitaire.kicad_sym`
with nickname `solitaire` (adjust the path to where the project file sits relative to this folder). Add
`solitaire.pretty` the same way under Manage Footprint Libraries, also with nickname `solitaire`.

## Checked

- MSP430FR2355TDBT: all 38 pins compared by script against Figure 4-3 (38-pin DBT pinout) of TI datasheet
  SLASEC4D. No differences, apart from two duplicated alternate names in TI's figure (UCA1RXD, UCA1TXD) listed once.
- LS013B7DH03: pins from Table 6-1 of Sharp spec LCP-2111042. The 3D model's glass, polarizers and active
  area follow Figure 5-1; the FPC tail outline is simplified.
- LS013B7DH05: pins from Sharp spec LD-26912A, identical to the DH03's. The 3D model follows Figure 8-1: glass
  24.68 x 30.0, polarizers 24.08 x 27.4, active area 20.88 x 24.36 centred 13.78 from the edge away from the FPC,
  0.745 thick. Sharp draws the FPC at the top; the model flips it to leave the bottom edge, like the DH03's. The
  FPC is modeled as a plain 9.47mm strip (its notches are left out).
- Panasonic AYF531035: pads from the recommended PC board pattern (page 7 of Panasonic's Y5B/Y5BW datasheet
  ACCTB1E 202110, `panasonic_y5b.pdf`): signal pads 0.30 x 0.80, hold-down pads 0.40 x 0.80, 1.00 outside the
  end pads and 2.50 behind them. Body 7.00 x 2.90 from page 4. Panasonic doesn't dimension the body against
  the pads, so the fab outline's front edge is an estimate; the pads themselves are as specified.
- Display capacitors: Figure 9-1 of Sharp spec LD-26912A asks for "rank B" (±10%, X7R-class) ceramics: 0.1µF
  DISP to VSS, 1µF VDDA to VSSA and 1µF VDD to VSS, placed at the FPC connector.
- Regulator capacitors: the parts TI recommends in Tables 8-3 and 8-4 of the TPS63900 datasheet (SLVSET3D). All
  capacitors are standard 0603s, so KiCad's IPC-7351 footprint is used rather than a custom one. TI's 22µF output value already
  allows for these parts losing up to half their capacitance at the 3V bias.
- Configuration resistors: values from Tables 7-2 and 7-3 of the TPS63900 datasheet, for 3.0V out at either
  SEL level and a 100mA input current limit. Each symbol is named for its pin, so the schematic can't swap them.
- ALPS SKRPACE010: pads from the PC board land drawing in ALPS's SKRP datasheet (`alps_skrp.pdf`): four
  1.05 x 0.65 pads, 3.1 / 5.2 apart in X and 1.5 / 2.8 in Y. ALPS's terminals 1-2 and 3-4 are joined inside the
  switch, so the footprint numbers its pads 1, 1, 2, 2 for a two-pin symbol. The 3D model follows the outline
  drawing (body 4.2 x 3.2, stem 3.0 x 2.2 reaching 2.5 above the board); its terminals are simplified.
- Murata DFE201612E: pads 0.8 x 1.8, 0.8 apart (2.4 overall), from the recommended PCB pattern in Murata's spec for
  the DFE201612P (`murata_dfe201612p_spec.pdf`), which has the same 2016 body; the DFE201612E's own product sheet
  (`murata_dfe201612e-2r2m.pdf`) gives no pattern. KiCad's `L_Murata_DFE201610P` is not used: its pads are
  smaller (0.55 x 1.6, 2.0 overall) and the 3D model it names isn't installed.

## Open items

- **Pin 1 orientation of the FPC.** The AYF531035 has contacts top and bottom, so the FPC can go in either
  face down. With the display face up and the FPC running straight into the connector (the FPC's contacts face
  the board), FPC lead 1 meets pad 1, as the symbol assumes. If the FPC is bent back so the display sits on top of
  the connector, the leads reverse (lead 1 meets pad 10); swap the pin numbers in the schematic for that layout.
- **The connector's 3D model** isn't in this library. Panasonic's CAD download for the AYF531035 has one.
- **Check the footprint against Panasonic's product specification** for the AYF531035 before ordering boards; the
  datasheet's pattern covers the whole Y5B/Y5BW family.
- **FPC bend:** only 0.8-6.0mm from the glass edge, inner radius at least 0.45mm, never toward the polarizer side,
  and no more than 3 bends.
- **EXTCOMIN:** the DH05 needs it toggled at 57-66Hz. Drive it from a Timer_B
  output clocked from ACLK so it keeps running in LPM3 without waking the CPU. EXTCOMIN must go on a timer
  output pin: P2.0/P2.1 (TB1.1/TB1.2) or P5.0/P5.1 (TB2.1/TB2.2) leave the SPI ports free.
